核心设计亮点

专注、高效、零阻碍的桌面任务管理体验

🚫

无任务栏图标 (Skip Taskbar)

完全隐藏在 Windows 系统任务栏及 Alt+Tab 列表中，不占用任务栏窗口空间，仅驻留托盘。

📌

常驻置顶与防误触锁定

始终悬浮在所有代码编辑器、浏览器上方。一键锁定后隐藏全部控件，防止误拖拽或误操作。

↕️

一键折叠为迷你胶囊

双击标题栏，瞬间收起为 42px 极简迷你栏（并显示今日未完成任务数），再次双击还原。

🎚️

透明度滑块与毛玻璃

支持 30% ~ 100% 不透明度实时滑动调节，极佳的高颜值 Dark Glassmorphism 视觉呈现。

📝

今日待办 & 明日计划

支持任务紧急度标记（🔴/🟡/🔵）、完成打勾划线动画、双击文本内联编辑与“一键归档移至明日”。

💾

SQLite 本地原生硬核存储

使用 Tauri SQLite 原生插件存储数据，随写随存，零延迟持久化，重启电脑绝对不丢任务。
